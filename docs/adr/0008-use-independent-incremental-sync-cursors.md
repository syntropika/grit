# Use independent incremental synchronization cursors

Grit will expose only `synced_at`, while internally synchronizing ordinary Issue changes with an overlapped `updated_at` watermark and idempotent upserts, and dependency changes with a separate event checkpoint. A dependency mutation is not guaranteed to advance `Issue.updatedAt`, and `synced_at` is therefore presentation metadata rather than either cursor. If Grit cannot prove event continuity, it performs a Full reconciliation; only a complete combined result replaces the Local replica. This keeps unchanged and small-delta runs lean without silently omitting older Issue updates or relationship changes.
