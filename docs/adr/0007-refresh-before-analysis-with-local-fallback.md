# Refresh before analysis with a local fallback

Before `next`, `plan`, `triage`, or `graph` calculates a result, Hyfa will attempt a pull-only synchronization from GitHub. A successful and complete synchronization atomically replaces the Local replica; when GitHub cannot be reached and a valid replica exists, analysis continues from that replica and reports its `synced_at`, without calculating or enforcing an age. If neither synchronization nor a valid replica is available, the command fails. Online mutations contact GitHub first; offline mutations may instead create Pending mutations without modifying the replica. Analysis never publishes those pending writes. This favors current data during normal use while preserving offline operation and a read-only analysis contract.
