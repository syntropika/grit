# Use priority labels as the only v1 source

Grit v1 will derive Declared priority exclusively from the canonical labels `priority:p0` through `priority:p4` in every Repository, with P0 as the highest priority. It will not discover or consume organization Issue Fields or Project fields for ranking. A missing priority label means unspecified priority. Multiple canonical labels produce a Priority conflict: Grit reports it, ignores all declared priority values on that Issue, and keeps the Issue eligible for graph-based ranking. This single representation is present in ordinary Issue payloads, works for personal and organization repositories, uses the established Issues permissions and REST operations, and avoids a second synchronization and configuration path. Support for typed Issue Fields may be added as an explicit adapter after v1. This decision supersedes ADR 0019's ownership-dependent source selection and all of ADR 0020.
