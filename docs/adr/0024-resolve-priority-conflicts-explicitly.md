# Resolve priority conflicts explicitly

When a Pending Priority update was based on one value and GitHub now contains a different value that is neither the base nor the desired result, Grit will preserve the operation as a Mutation conflict and expose its base, local, and remote values. `grit resolve OPERATION --remote` accepts GitHub's value and retires the pending operation without writing. `--local` explicitly reaffirms the local value, while `--priority p0|p1|p2|p3|p4|none` replaces it with a new choice; both update the operation's base to the observed remote value and retry optimistic reconciliation. A further remote change can conflict again. Grit will not choose automatically: robot output reports the conflict as structured JSON, dependent operations remain blocked, and independent mutation branches continue under ADR 0016.
