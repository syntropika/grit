# Use field-aware optimistic conflict detection

Each Pending mutation will retain the relevant base value and desired result. During Mutation reconciliation, Grit applies it when the remote field still equals the base, treats it as satisfied when the remote value already equals the desired result, and reports a Mutation conflict when both remote and local changed incompatibly. Conflicting titles and bodies require explicit resolution with base, local, and remote values; v1 will neither use last-write-wins nor automatically merge Markdown. Append-only comments and generic set-like label or dependency operations use their natural idempotent semantics instead of conflicting on unrelated field changes. Canonical `priority:*` labels are the storage representation of one logical value and follow the scalar conflict rules in ADR 0024.
