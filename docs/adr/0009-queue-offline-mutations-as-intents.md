# Queue offline mutations as intents

Grit will represent offline writes—including Issue creation, title and body edits, comments, state, assignment, labels, and dependency changes—as durable Pending mutations in an outbox, never as direct edits to the Local replica. On reconnection, Mutation reconciliation first refreshes from GitHub, then classifies each intent as applicable, already satisfied, or conflicting; it applies applicable operations to GitHub, treats already-satisfied operations idempotently, blocks conflicts and their dependents instead of using last-write-wins, and finally synchronizes again. Independent branches may continue. This preserves GitHub as the sole source of truth while allowing disconnected work, at the cost of explicit conflict handling and an additional local state machine.
