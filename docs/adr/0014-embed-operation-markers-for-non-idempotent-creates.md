# Embed operation markers for non-idempotent creates

Before sending an offline-created Issue or comment, Grit will persist a random operation ID and embed it in the Markdown as an invisible HTML Operation marker. If the request outcome is ambiguous, Mutation reconciliation searches the relevant recent remote content for that marker before retrying, preventing ordinary timeout recovery from duplicating Issues or comments; absence or ambiguity leaves the operation unresolved rather than triggering a blind retry. Markers contain no user data or credentials, remain hidden when GitHub renders Markdown, and are stripped from terminal, JSON, and public Pages output. This adds a small metadata marker to the raw content because GitHub does not document server-side idempotency for these creates.
