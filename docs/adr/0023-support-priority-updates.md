# Support priority updates

Grit v1 will support `grit update ISSUE --priority p0|p1|p2|p3|p4|none`. The command represents one logical Priority update: a P0–P4 value removes every other canonical `priority:*` label and leaves exactly the requested one, while `none` removes all canonical priority labels. It never changes non-priority labels or GitHub Issue and Project fields. When GitHub cannot be reached, the operation is persisted as a Pending mutation and projected into the Working graph under the existing offline mutation rules. Applying either a concrete value or `none` also resolves any pre-existing Priority conflict on that Issue. Concurrent remote changes to this logical value are resolved under ADR 0024 rather than generic set-like label semantics.
